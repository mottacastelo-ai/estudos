🟢 Multiplicação

Fator × Fator = Produto Comutativa: a×b = b×a Associativa: (a×b)×c = a×(b×c) Distributiva: a×(b+c) = a×b + a×c Elemento neutro: a×1 = a Dobro (×2) / Triplo (×3) / Quádruplo (×4) Quíntuplo (×5) / Sêxtuplo (×6) Multiplicar por 10: acrescenta 1 zero

🔵 Divisão

Dividendo ÷ Divisor = Quociente + Resto Divisão exata: resto = 0 Divisão não exata: resto ≠ 0 Verificação: quociente×divisor+resto = dividendo Relação inversa com multiplicação

🟡 Expressões Numéricas

Multiplicação antes de adição/subtração 1º Parênteses ( ) 2º Colchetes [ ] 3º Chaves { }

🟣 Termo Desconhecido

Sentença matemática com □ Usar operação inversa Ex: □×6=48 → 48÷6=8
