📖 O que significa cada conceito
• mdc: maior valor da intersecção ∩ dos conjuntos de divisores
• mmc: menor valor (≠0) da intersecção ∩ dos conjuntos de múltiplos
• Fatores Comuns: bases que aparecem em todos os números → usamos no mdc
• Menores Expoentes: para mdc, pegar o menor expoente de cada base comum
• Maiores Expoentes: para mmc, pegar o maior expoente de cada base
• Todos os Fatores: mmc usa fatores comuns E não-comuns
• Primos entre si: mdc=1 → mmc = produto dos números
• Intersecção ∩: símbolo que indica o que é comum entre conjuntos
