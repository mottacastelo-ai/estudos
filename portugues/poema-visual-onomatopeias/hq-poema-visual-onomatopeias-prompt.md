### PÁGINA 2 — "Palavras que Viram Gato" (Imobilidade)
**Objetivo pedagógico:** Mostrar o poema visual "Canção para ninar gato com insônia" (Sérgio Capparelli) como exemplo de poema que sugere **imobilidade**; introduzir o conceito de **onomatopeia** ("zzz", "ron ron").

**PROMPT:**
```

Panel 1: Ziguinho stands in his default letter-body form, holding up a large scroll. On the scroll is a title written in cursive: "Canção para ninar gato com insônia — Sérgio Capparelli".
```
